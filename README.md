# 🐦 Flappy Bird Game

A Python recreation of the classic Flappy Bird. Tap to flap, fly through the gaps between pipes and beat your high score.

## Gameplay

- Press **Space** (or click) to make the bird flap
- Gravity pulls the bird down
- Pass through pipe gaps to score; hitting a pipe or the ground ends the game

## Features

- Smooth physics with gravity and flap
- Endlessly generated pipes
- Score tracking
